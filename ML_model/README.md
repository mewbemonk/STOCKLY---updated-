# 📈 LSTM Stock Forecast Dashboard

A modular Streamlit app that uses an LSTM neural network to forecast stock prices for major tickers like S&P 500, Apple, Tesla, Reliance, and Infosys. Built for analysts, learners, and curious investors.

---

## 🚀 Features

- 🔮 Forecast next 5–15 days of closing prices using LSTM
- 📊 Visualize actual vs predicted trends with interactive plots
- 📉 Detect forecast trend: Uptrend, Downtrend, or Sideways
- 📋 View last 60 trading days with OHLCV data
- 🧠 Modular design for teaching, deployment, and extension
